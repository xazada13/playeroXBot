ЛИЧНЫЙ БОТ ДЛЯ PLAYEROK. ИНСТРУКЦИЯ ЗАПУСКА (Windows)

ЧТО НУЖНО ОДИН РАЗ
1. Установите Python 3.11 или новее с python.org.
   При установке ОБЯЗАТЕЛЬНО поставьте галочку "Add Python to PATH".
2. Создайте Telegram-бота: напишите @BotFather, команда /newbot,
   скопируйте выданный токен.
3. Распакуйте эту папку, скопируйте файл .env.example и назовите копию .env
   (именно так, с точкой в начале). Откройте .env в блокноте и вставьте
   токен бота после TG_BOT_TOKEN=

ЗАПУСК
4. Откройте папку, в адресной строке проводника напишите cmd и нажмите Enter.
5. Выполните по очереди:
      pip install -r requirements.txt
      python login.py
   login.py сначала попробует войти по коду из письма. Если сайт ответит
   ошибкой, скрипт покажет, как взять токен из браузера (F12 -> Application ->
   Cookies -> playerok.com -> token) и попросит его вставить.
   Токен сохранится в .env.
6. Выполните:  python bot.py
7. Напишите вашему боту в Telegram команду /id. Он пришлёт число.
   Впишите его в .env после OWNER_ID= , остановите бота (Ctrl+C)
   и запустите снова: python bot.py
8. Напишите боту /start. Откроется меню.

ВАЖНО
- Бот работает, пока включён компьютер и открыто окно с ним.
  Для работы 24/7 нужен сервер (VPS), я помогу настроить позже.
- Файл .env никому не показывайте: токен даёт доступ к аккаунту.
- Первый раз проверьте всё на тестовом объявлении.
- Если что-то не работает (поднятие, восстановление, удаление),
  отправьте боту /diag и пришлите мне ответ. Я подправлю названия
  методов за один шаг.
- Если бот пишет ошибку, пришлите последние строки из файла bot.log.

АВТО-ПОДТВЕРЖДЕНИЕ (для товаров с автовыдачей Playerok)
/start -> "Сценарии по объявлениям" -> выберите объявление ->
"Авто-подтверждение: включить". После оплаты бот сам отметит заказ выданным.
Объявления с включённой функцией помечены значком ⚙️ в списке.

СЦЕНАРИИ ПО ОБЪЯВЛЕНИЯМ (всё делается в боте)
/start -> "Сценарии по объявлениям" -> "Добавить по ссылке".
Вставьте ссылку на объявление, затем выберите сценарий
(после оплаты / после выдачи / после подтверждения / при проблеме)
и пришлите текст. "-" возвращает общий текст. Если для объявления текст
не задан, берётся общий авто-ответ из пункта "Общие авто-ответы".

КОМАНДЫ
/cancel          отменить ввод текста или ссылки
/start           главное меню
/settext paid Текст    изменить текст автоответа (paid, sent, confirmed, problem)
/diag            список методов библиотеки (для настройки)
/id              показать ваш Telegram ID
